พื้นที่ประกอบ

รูปแบบคำสั่งที่เครื่องมือนี้อ่านได้
FOR i ← 0 TO n - 2
  ...
END FOR
WHILE j >= 0 AND A[j] > key
  ...
END WHILE
IF A[j] < A[minIndex] THEN
  ...
END IF
minIndex ← i
key ← A[i]
A[j + 1] ← A[j]
SWAP A[i], A[minIndex]

ดัชนีเริ่มที่ 0 • FOR รวมค่าปลายทาง
ใช้ <- หรือ ← เพื่อกำหนดค่า • คำสั่งภาษาอังกฤษ
รองรับตัวแปร i, j, n, key, minIndex
ใช้ IF / WHILE / FOR ตามรูปแบบนี้
เว้นวรรคและการเยื้องได้ โดยใช้ END ปิดบล็อก
